## API Reference
- [Validate Account](https://docs.prometeoapi.com/reference/validate_account_api_v2_validate_account_post.md)
- [Retrieve Validation Result](https://docs.prometeoapi.com/reference/retrieve_validation_result_api_v2_validate_account__request_id__get.md)
- [Retorna detalles de la cuenta consultada.](https://docs.prometeoapi.com/reference/post_validate-account-1.md): Valida que una cuenta sea valida y retorna información asociada a su dueño.
- [Confirma el titular de la cuenta consultada.](https://docs.prometeoapi.com/reference/post_account-ownership.md): Valida el nombre del titular de una cuenta.
- [Login](https://docs.prometeoapi.com/reference/login.md): Iniciar sesión con una institucion financiera
- [Logout](https://docs.prometeoapi.com/reference/logout.md): Cierra la sesión actual, luego de esto la clave de sesión dejará de ser válida.
- [Clientes](https://docs.prometeoapi.com/reference/getclients.md): Los clientes son cuentas asociadas a un usuario, un usuario puede tener más de una cuenta asociada a su usuario. Sucede mucho en el caso de cuentas con 2 dueños.
- [Seleccionar cliente](https://docs.prometeoapi.com/reference/selectclient.md): Selecciona el cliente a usar en la sesión
- [Login Procedure](https://docs.prometeoapi.com/reference/login-procedure.md): Enviar preguntas de seguridad
- [Información del titular](https://docs.prometeoapi.com/reference/getpersonalinfo.md): Obtiene información del titular de la cuenta bancaria que inició sesión
- [Cuentas](https://docs.prometeoapi.com/reference/getaccounts.md): Obtener las cuentas del usuario
- [Listar movimientos](https://docs.prometeoapi.com/reference/getmovements.md): Obtiene todos los movimientos de una cuenta en un rango de fechas
- [Detalle de movimiento (EXCLUSIVO SCOTIA EMPRESAS PERÚ)](https://docs.prometeoapi.com/reference/getmovementdetail.md): Retorna informacion extra sobre un movimiento **ESTE ES UN ENDPOINT EXCLUSIVO PARA SCOTIA EMPRESAS PERÚ**
- [Listar tarjetas de crédito](https://docs.prometeoapi.com/reference/getcreditcards.md): Lista todas las tarjetas de crédito del usuario
- [Listar movimientos de una tarjeta](https://docs.prometeoapi.com/reference/getcreditcardmovements.md): Lista todos los movimientos de una tarjeta de crédito para un rango de fechas
- [Verifica el estado de la tarea](https://docs.prometeoapi.com/reference/gettaskresult.md): Verifica el estado de la tarea, si esta completada retorna el resultado de la misma. (Solo aplica al proveedor Bancolombia Empresas de Colombia)
- [Campos requeridos para preinscribir una cuenta](https://docs.prometeoapi.com/reference/gettransferenrollform.md): Listar los campos requeridos para preinscribir una cuenta para transferencias
- [Preinscribir cuenta para transferencias (requerido solo en algúnos providers)](https://docs.prometeoapi.com/reference/transferaccountenroll.md): Preinscribe una cuenta para poder realizar transferencias <br /> Los parámetros opcionales serán necesarios según cada provider
- [Confirma la preinscripción cuando requiere autorización posterior](https://docs.prometeoapi.com/reference/transferaccountenrollconfirm.md): Utiliza autenticación de múltiples factores para confirmar la preinscripción (por ej. SMS, EMAIL)
- [Remover cuenta preinscrita](https://docs.prometeoapi.com/reference/transferaccountenrollremove.md): Remueve una cuenta preinscrita con anterioridad (solo disponible para los proveedores Banorte Corporativo Mexico y Davivienda Corporativo Colombia)
- [Listar instituciones para transferencias](https://docs.prometeoapi.com/reference/gettransferdestinations.md): Lista las instituciones financieras hacia donde se pueden realizar transferencias
- [Campos requeridos para realizar una transferencia](https://docs.prometeoapi.com/reference/gettransferformfields.md): Listar los campos requeridos para realizar transferencias hacia una cuenta (aplica solo al proveedor Banco de Bogotá Corporativo de Colombia)
- [Métodos de autenticación requeridos para realizar una transferencias](https://docs.prometeoapi.com/reference/gettransfermfa.md): Listar los tipos de autenticación requeridos para realizar transferencias hacia una cuenta (por ahora solo para `santander_pers_uy`)
- [Preprocesar transferencia](https://docs.prometeoapi.com/reference/transferpreprocess.md): Aprueba y valida los datos necesarios para realizar la transferencia
- [Reintento de preprocesar la transferencia](https://docs.prometeoapi.com/reference/retrytransferpreprocess.md): Reintento de la transferencia con los mismos datos suministrados (por ahora solo para `santander_pers_uy`)
- [Confirmar transferencia](https://docs.prometeoapi.com/reference/transferconfirm.md): Confirma una transferencia ya preprocesada
- [Obtener detalles de la transferencia](https://docs.prometeoapi.com/reference/transferdetail.md): Devuelve el estado y los detalles de la transferencia (solo aplica al proveedor Bancolombia Corporativo Colombia)
- [Obtener listado de transferencias realizadas](https://docs.prometeoapi.com/reference/gettransferlog.md): Devuelve un listado de las transferencias realizadas a través de la API en un periodo de tiempo especificado. Incluye transferencias de todos los providers utilizados.
- [Detalle de transferencia](https://docs.prometeoapi.com/reference/gettransferlogdetail.md): Devuelve el detalle de una transferencia dado su request_id
- [Comprobar que la cuenta sea válida](https://docs.prometeoapi.com/reference/validateaccount.md): Comprueba que la cuenta sea válida (solo aplica a los proveedores Banco República de Uruguay y de Perú BBVA Netcash, Telebanking Corporativo e Interbank Corportativo)
- [Preprocesar lote de transferencias](https://docs.prometeoapi.com/reference/preprocessbatchtransfer.md): Aprueba y valida los datos necesarios para realizar las transferencias de un lote (solo disponible para el proveedor Telecrédito - BCP de Perú)
- [Confirmar un lote transferencia](https://docs.prometeoapi.com/reference/confirmbatchtransfer.md): Confirma un lote de transferencias ya preprocesadas (solo disponible para el proveedor Telecrédito - BCP de Perú)
- [Obtener los detalles de un lote de transferencias](https://docs.prometeoapi.com/reference/detailbatchtransfer.md): Devuelve el estado y los detalles de la transferencia (solo disponible para el proveedor Telecrédito - BCP de Perú)
- [Listar proveedores](https://docs.prometeoapi.com/reference/getproviders.md): Lista todos los proveedores de datos disponibles en Prometeo
- [Detalle de proveedor](https://docs.prometeoapi.com/reference/getproviderdetail.md): Detalles adicionales sobre el proveedor
- [Lista las sucursales del proveedor](https://docs.prometeoapi.com/reference/getproviderbranches.md): Lista las sucursales del proveedor dentro de una zona postal (solo aplica al proveedor BBVA Mexico)
- [Lista los cajeros del proveedor](https://docs.prometeoapi.com/reference/getprovideratms.md): Lista los cajeros del proveedor dentro de una zona postal (solo aplica al proveedor BBVA Mexico)
